# Splunk SSH Analyzer

## Project Overview
I am working on improving my Splunk and cybersecurity skills. Through this project, I will analyze SSH authentication logs using Splunk Enterprise to investigate login activity and identify potentially suspicious behavior. This project follows the guide found here https://github.com/0xrajneesh/Splunk-Projects-For-Beginners/blob/main/project%234-analyzing-ssh-logs-using-splunk-siem.md .

## Objectives
- Import and explore SSH log data.
- Practice Splunk Search Processing Language (SPL).
- Analyze successful and failed login attempts.
- Identify unusual authentication patterns.
- Create a dashboard to visualize findings.

## Tools
- Splunk Enterprise 10.4.1
- Visual Studio Code
- Git and GitHub

## Dataset
SSH sample logs from Security Repository (SecRepo).

## Project Status 
In Progress – Currently setting up the project environment and preparing the SSH log dataset for analysis.
